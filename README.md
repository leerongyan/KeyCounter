# 键盘鼠标使用统计工具

一个在 Windows 本地运行的统计工具：

- 统计每个键盘按键的使用次数
- 生成键盘热力图
- 统计鼠标左键、右键、中键、滚轮次数
- 统计鼠标移动距离
- 通过本地网页查看实时数据

## 如何运行

1. 双击项目目录中的 `start.bat`
2. 程序会自动打开浏览器，地址是 `http://127.0.0.1:8765`
3. 点击页面右上角按钮可以暂停、开机自启、导出数据或下载热力图
4. 程序启动后会出现在系统托盘，右键托盘图标可以暂停、更新开机自启、导出 CSV、退出
5. 在黑色命令行窗口按 `Ctrl+C` 可以停止程序

也可以手动运行：

```powershell
cd D:\codex_project\Key_counter
python app.py
```

## 打包成 exe

双击 `build_exe.bat`，等待打包结束，生成的文件在 `dist\KeyCounter.exe`。打包完成后可以把 exe 复制到其他 Windows 电脑直接使用。

## 数据保存在哪里

统计数据保存在项目目录下的 `data\keycounter.db` 文件中。

## 隐私说明

本软件只记录按键名称和次数，例如 `A`、`Enter`、`Ctrl`，不会保存输入的文字内容、按键顺序、窗口标题或剪贴板内容。数据只保存在本地，不会上传。
